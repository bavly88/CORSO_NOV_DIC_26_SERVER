Righe da cambiare nel file .env del progetto (sezione database).

Prima (progetto nuovo, SQLite):
DB_CONNECTION=sqlite
# DB_HOST=127.0.0.1
# DB_PORT=3306
# DB_DATABASE=laravel
# DB_USERNAME=root
# DB_PASSWORD=

Dopo (MariaDB del corso):
DB_CONNECTION=mariadb
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=bookshelf
DB_USERNAME=corso
DB_PASSWORD=corso

Prima di php artisan migrate, in HeidiSQL: CREATE DATABASE bookshelf;
